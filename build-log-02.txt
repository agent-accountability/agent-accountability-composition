  check-refs.py (verbatim):
    # check-refs.py <xml>: every <reference anchor> must be the target of an <xref> before <back>
    import re, sys
    x = open(sys.argv[1]).read()
    body = x[:x.index("<back>")]
    anchors = re.findall(r'<reference anchor="([^"]+)"', x)
    unused = [a for a in anchors if 'target="%s"' % a not in body]
    print("references: %d  unused: %s" % (len(anchors), ", ".join(unused) or "none"))
    sys.exit(1 if unused else 0)

    not relied on here: its citation pattern misses citations written as "([X])"
    (lib/parsers/txt.mjs). See REFERENCE_NOT_USED below.

    checklist). Mutant: citing AAC -04 is reported as "Outdated reference: A later
